# Changes

[Deutsch](CHANGELOG.de.md)

## 1.0.1 – November 2026

Fixes for the Mac app. Version 1.0 did not start on Macs other than the build machine.

- The app no longer crashes at launch (a speech library was missing from the package).
- The bundled Python runs without Homebrew.
- Setup downloads the speech model (Whisper Large v3, about 3 GB) itself and checks it.
- The window no longer shrinks to an invisible size.

## 1.0 – October 2026

First version for Mac and iPhone.

- Mac: Hold a key to dictate, pill at the edge of the screen, history with search and calendar, dictionary.
- iPhone: Dictation keyboard, history, dictionary, storage & data for cleanup.
